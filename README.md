# Universal Healthcare Social — Homepage v2

Static publishing website for unitedhealthcaresocial.com.

## Homepage
Splash screen, followed by two clickable illustrated article cards in this order:
1. Medicare for All and Business
2. Medicare for All and Dentists

The article titles appear **inside the illustrations**. Each card includes a short descriptive paragraph below. Clicking anywhere on the card opens the article.

## Preview
Open `index.html` in a browser.

## Publish
Push the contents to a GitHub repository and enable GitHub Pages (Deploy from branch, root). Set the custom domain only after DNS is configured. Render is not needed for this static website.

## Notes
Existing additional article pages remain in the package but are not linked on the homepage. All article pages currently contain starter text that can be replaced with full essays.
