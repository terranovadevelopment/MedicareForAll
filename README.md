INSTALL
1. In GitHub Desktop, select the MedicareForAll repository and choose Repository > Show in Explorer.
2. Open this ZIP and select ALL files and folders inside it (including the assets folder).
3. Extract/copy them into the repository folder, replacing files when asked. Do NOT delete the .git folder.
4. Check in Windows File Explorer that assets/universal-healthcare-banner.png and assets/article-covers/can-we-afford-it.png exist.
5. GitHub Desktop > Changes > Commit to main > Push origin. Wait for GitHub Pages to deploy, then Ctrl+F5.

The ZIP contains the COMPLETE website, not just the changed HTML.
